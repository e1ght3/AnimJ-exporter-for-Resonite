# はじめての操作

対象：Blenderアドオン0.3.1／AnimJ Library 0.1.0-preview。確認環境はBlender 5.0.1です。Resonite内ではInspectorを使います。ResoniteLink・Resoloopは不要です。

## 1. Blenderへインストール

1. `downloads/animj_exporter_for_resonite-0.3.1-preview.zip` を保存します。解凍しません。
2. Blenderで「編集 → プリファレンス → アドオン」を開きます。
3. 右上メニューの「ディスクからインストール」でZIPを選びます。
4. `AnimJ exporter for Resonite` を有効にします。旧版から更新した場合はBlenderを再起動します。

成功すると「ファイル → エクスポート」に同名の項目が表示されます。

## 2. 最初のモデルと動きを出力

1. 動きのあるblendファイルを開き、タイムラインで動きを確認します。
2. 出力するメッシュと必要なオブジェクトを選びます。Armatureだけの選択ではメッシュは出力されません。モデル一式をCollectionにまとめても構いません。
3. 「ファイル → エクスポート → AnimJ exporter for Resonite」を選びます。
4. `Objects` を `Selected Objects` または `Collection` にします。後者はCollection名も指定します。
5. `Export FBX` をオン、`Connection` を `Resonite: Setup fields by name` にします。
6. 開始・終了フレームを設定します。最初はサンプリング間隔を1にしてください。
7. 静的シェイプ調整を固定してよいモデルでは `Bake Start Shape` を選べます。シェイプ自体を残す場合は保持設定を使い、取り込み後の初期値を別途確認します。
8. 新しい保存先を指定し、エクスポートします。既存の出力フォルダーは上書きされないため、再出力は別名にします。

作られる `.resobundle` は**フォルダー**です。中の `model.fbx` と `motion.animj` を使います。`export-report.json` と `READ-ME.txt` も保管してください。

## 3. Resoniteへ取り込む

次のURI全体をコピーし、Resonite内でペーストして、空のAnimJ Libraryを取得します。

```text
resrec:///U-e1ght3/R-8C6EDDC35C6751EA3D8F52ECF53E61BDC81EF8D773D75369B8E8E3ADF1BE6782
```

別モデル入りのアイテムへ上書き投入しないでください。モデルは着用しません。

1. `model.fbx` をResoniteへドラッグします。
2. ダイアログの「高度な設定」で次の値にします。

| 項目 | 値 |
| --- | --- |
| Scale | 1 |
| Auto Scale | オフ |
| Rig / Import Bones | 両方オン |
| Setup IK / Force T-Pose / Animations | すべてオフ |
| Assets on Object / Import at Origin | 両方オン |
| Colliders | オフ |

3. 設定後に「3Dモデル」プリセットを選び直さず、インポートします。
4. 続けて `motion.animj` をResoniteへドラッグします。

## 4. パネルへモデルと動きを登録

1. Inspectorを開き、Root直下の**取り込んだモデル全体の外側Slot**を探します。
2. そのSlotをつかみ、パネル上段のモデル入力欄へドロップします。
3. ツール内の `Animation Model → Model_Here` の子へモデルが移ったことを確認します。内側の `RA_…` 名は変更しません。
4. パネルの「＋空の行を追加」を1回押します。
5. Inspectorから取り込んだAnimJのSlotをつかみ、その空行の入力欄へドロップします。Slotは `Clips_Here` に移動します。
6. 名前が表示された行の「選択」を押し、読み込みを待ちます。

**プレビューの注意：** 既存行へのクリップドロップ・自動保管・再生は確認済みです。実モデルのドロップ、新規行のドロップ、選択中行への差し替えは確認途中です。失敗した場合は症状を作者へ知らせてください。階層を無理に組み替えず、空の新しいコピーからやり直せます。

## 5. 初回だけ接続

1. Inspectorでツール内の **Animation Model** を開きます。
2. Animatorの **Setup fields by name** を1回押します。
3. `Fields` が増えたことを確認します。期待値は `export-report.json` の `tracks` です。522はテストモデルの例で、すべてのモデルに当てはまりません。
4. パネルの **▶** を押します。**Ⅱ** で一時停止します。

「選択済み」は初回接続の完了を示しません。Fieldsの件数が同じでも接続先の正しさまでは保証されません。動かない部分や大きな崩れがあれば一時停止してください。

## 6. 別の動きを追加

1. Blenderで同じモデルに別の動きを用意します。オブジェクト名、骨格、親子関係、出力対象は変えません。
2. 今度は `Export FBX` をオフにします。`Existing Model (optional)` に最初の `.resobundle` フォルダーを指定すると対象やrest姿勢の照合ができます。
3. 別名の出力先へ書き出し、新しい `motion.animj` だけResoniteへ投入します。
4. 同名のクリップが既にある場合は、新しく取り込んだ**外側Slot**を `Walk` など区別できる名前へ変更します。
5. パネルで空行を追加し、新しいクリップをドロップ →「選択」→ ▶ と操作します。

同じ対象名・プロパティ・型・順序のクリップなら初回Setupを繰り返す必要はありません。別モデルの動きはそのまま流用できません。

## 7. 整理と保存

| 操作 | 意味 |
| --- | --- |
| ▲ / ▼ | 行を上／下へ移動 |
| × | 行だけ削除。保管済みクリップは残る |
| ▶ / Ⅱ | 再生／一時停止 |
| ↻ | ループ切り替え |

保存するときは、**ツールの一番外側のSlot全体**をインベントリへ保存します。パネルだけ、モデルだけを保存すると必要な参照が分離します。配布する自作モデルの権利も別途確認してください。

## 動かないとき

| 症状 | 確認・操作 |
| --- | --- |
| モデルは配置済み | 別モデルの置き換えはできません。空のツールを新しく取り出す |
| 同名の別クリップ | 新クリップの外側Slot名を変えて再ドロップ |
| 読み込み待ち | アセットの読み込みを待ち、再度「選択」 |
| 選択できるが動かない | Animation Modelの初回Setup、Fields、対応するFBXとAnimJの組を確認 |
| 崩れる／一部が動かない | Ⅱで止め、別モデルのクリップやIK競合がないか確認 |
| Blenderの出力エラー | エラーに記載された対象とフレームを確認。元blendと出力ログを手元に保管 |

不具合報告には、Blender／アドオン／ツールの版、行った操作、期待した動き、実際の結果、エラー文を添えてください。第三者モデルや個人情報は公開Issueへ添付しないでください。
