# 開発プレビューの制限

- Blender 5.0.1で確認。すべてのBlender版・モデルへの対応保証はありません。
- オブジェクトとボーンのTRSが対象。Shape Keyの時間変化、任意モデル間のリターゲット、着用中アバターのエモートは未対応です。
- 初回のSetup fields by nameは手動。未接続・非互換クリップの自動診断は未実装です。
- 静的シェイプを保持しても、Resoniteでは初期ウェイトが0になり、微小シェイプが省略されたり名前が変化したりします。
- 一部のModifier、Preserve Volume、B-Boneの複数セグメント、物理、インスタンス、ゼロ・負のScale、shear等は出力できません。対応外はエラーになります。
- 材質・画像・スキン変形・法線の完全な一致は保証しません。
- 自動保管のモデル実ドロップ、新規行へのドロップ、選択中行の差し替えは確認途中。複数人・ホスト交代・権限不足も未検証です。
- 自動保管の移動と登録をまとめたUndoは未対応です。元モデルを保持し、新規取り込みコピーで試してください。
- 行数の固定上限はありませんが、多数行の性能上限は未調査です。
- 既存版で保存コピー／Link未使用の別セッション再生を確認しましたが、今回の空の配布アイテムで同じ試験を再実施したという意味ではありません。

通常利用にResoniteLink・Resoloop・PC側常駐プログラムは不要です。Resonite側のアセット取得と標準インポートは必要です。
